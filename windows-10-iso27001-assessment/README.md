# ISO/IEC 27001:2013 Windows 10 GRC Security Assessment

This assessment documents a Governance, Risk, and Compliance (GRC) review of a Windows 10 environment against ISO/IEC 27001:2013.

## Results

- **30 total findings**
- **28 resolved**
- **2 open**
- **12 high-risk findings**
- **30+ ISO 27001 controls mapped**

## Scope

The assessment covered local accounts and permissions, password and lockout policies, Windows Firewall, updates and vulnerability management, audit logging, encryption, credential storage, removable media, Microsoft Defender, RDP, and backup/recovery controls.

## Open Findings

1. No Data Encryption for Customer Data — High — ISO 27001 A.10.1.1
2. Admin Account With Unrestricted Privileges — High — ISO 27001 A.9.2.3
